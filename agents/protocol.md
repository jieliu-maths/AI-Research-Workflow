# Research protocol

Use [WORKFLOW.md](../WORKFLOW.md) as the sole execution protocol. Default to
continuous research in the current window. This compatibility entry point adds
no role topology, dispatch contract, runtime registry, or duplicate record.

For an ordinary session use brief.md, work.md (including the mathematical
summary), and manifest.json. Read the short approved STATE first; consult
relevant evidence only as needed. Freeze submitted artifacts and preserve
corrections separately. Key evidence needs independent review; formal changes
also need explicit human approval. Follow WORKFLOW.md for exact triggers,
preflight, review read order, evidence scope, and owner gates.
