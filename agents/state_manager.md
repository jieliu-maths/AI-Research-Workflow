# Approved-state synchronization

Follow the approved-record section of [WORKFLOW.md](../WORKFLOW.md). This is a
main-window activity, not a separate role. Propose formal changes with exact
frozen evidence, independent review, and scope; wait for explicit human approval.
Then update only affected canonical records and their mirror and validate.
Use links rather than copying results across logs and indexes. Reading reports
are optional generated views; report defaults to Markdown, with tex/pdf exports
on request. Never silently refresh canonical hashes before approval.
