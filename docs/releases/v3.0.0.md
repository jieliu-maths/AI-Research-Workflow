# 3.0.0 — single-window mathematical research

Default to continuous work in one window, a short approved-state entry, and
independent review only at key evidence gates. Ordinary sessions have three
files: brief.md, work.md (including final mathematical summary), manifest.json.
Use indexed evidence, review, state transitions, and route review when triggered.
No role task setup, fixed task titles, registry, or completion loop is required.

Local work proceeds within the owner-approved target, main route, hypotheses,
and exploration scope. Key identities, core estimates, claimed proof-gap
closures, and formal promotions need independent review; self-checks do not
qualify. Canonical conclusions, notation, and manuscript still need explicit
human approval. Validation is structural, not a mathematical certificate.

Report defaults to Markdown; --format tex and --format pdf are optional exports.
PDF tooling never blocks ordinary research. Legacy run schemas and records
remain accepted and unchanged. See WORKFLOW.md and the upgrade reference for
exact v2.7.0 document adoption and conflict handling of locally modified files.
No installed mathematical project is upgraded merely by modifying this source.
No controlled effectiveness experiment has been completed in this release.
