# 3.1.0 — mathematical feedback with light records

Implements the six owner-approved improvements: intended-question/source checks,
executable evaluator plans, bounded compute escalation, claim/proof version
review, information-gain route review and frozen-task comparisons with human
blind grading. Ordinary sessions still use brief/work/manifest; every additional
record is conditional. Formal state and manuscripts retain explicit approval.

New manifests are 1.3, claim evidence is 1.0 and version-bound reviews are 1.1.
Historical records are not rewritten and project-state schema remains 2.1.
Local checks enforce timeouts, not model billing or mathematical truth; benchmark
tools prepare packets and aggregate human grades but never invoke models.
Synthetic examples validate mechanics, not actual research productivity.
The kernel also recognizes the legacy delivery-manifest shape without counting
it as research evidence. An optional project-owned recovery note points from
approved state to exact working drafts and reviews. Existing briefs now prompt
for exact differentiated objects, coordinate maps and the scope of source checks.
See docs/research-feedback.md for commands, evidence limitations and migration.
