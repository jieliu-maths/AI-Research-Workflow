# Experimental AI4S workspace / AI4S 试验项目

Start with `PROJECT_CHARTER.md` and `WORKFLOW.md`. Obtain owner approval of
the exact question and route, then create the independent role tasks. Copy
`experiments/plan-template.md` for each approved run. This scaffold does not
run experiments or create application tasks automatically.

先填写项目章程，按 `WORKFLOW.md` 明确假设、证据、对照和停止条件。
研究目标和路线经负责人批准后，再建立独立角色任务。每轮复制实验计划
模板，保留原始数据、失败结果和独立审查。实验证据不等同于数学证明。

The bundled `WORKFLOW-LICENSE` covers these workflow assets; choose the
licensing and access terms for your own research separately.
