# Research runs

Each run is a frozen, inspectable trace of one Plan--Construct--Critique--Test--
Adjudicate cycle. Runs begin only after the literature, problem, and route gates
in `WORKFLOW.md` have initialized the project charter, proof ledger, and proof
map. Copy `_template/` to `YYYY-MM-DD-RNN/`. Raw artifacts are not canonical
mathematical truth and should not be rewritten after adjudication; corrections
go in a resolution artifact or later run.
